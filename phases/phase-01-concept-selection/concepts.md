# Концепции проекта

| Код | Концепция | Краткое описание |
|---|---|---|
| A1 | Запись на приём к врачу | Система для организации записи на врачебный приём. |
| A2 | Учёт вещей на хранении | Система учёта вещей, переданных на хранение. |
| A3 | Учёт обслуживания автомобиля | Система учёта обслуживания автомобиля. |
| A4 | Аренда инструментов между пользователями | Система организации аренды инструментов между пользователями. |

Названия взяты из [исходной таблицы](https://docs.google.com/spreadsheets/d/1eqROJSJggUz9f7V3TO8Hx18-0x1MoO2HRUv8ptMTKsc/edit). В документации исправлена опечатка «инструметов»; экспорт сохраняет оригинал.

Краткие описания поясняют названия. После выбора A1 детализирована только выбранная концепция; остальные варианты сохраняются как альтернативы из исходной таблицы. [MVP системы записи на приём к врачу](mvp.md) содержит границы, акторов, 12 Use Cases и критерии приёмки.
