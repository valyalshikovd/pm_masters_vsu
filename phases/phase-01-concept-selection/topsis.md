# Нечёткий коллективный TOPSIS

Ниже описана фактическая реализация в [таблице](https://docs.google.com/spreadsheets/d/1eqROJSJggUz9f7V3TO8Hx18-0x1MoO2HRUv8ptMTKsc/edit) и [экспорте](artifacts/phase-01-topsis.xlsx). Индексы i, j, k обозначают концепцию, критерий и анкету.

1. **Индивидуальные оценки.** Лингвистические значения переводятся в тройки xᵏᵢⱼ = (aᵏᵢⱼ, bᵏᵢⱼ, cᵏᵢⱼ); веса wᵏⱼ задаются аналогично.
2. **Агрегирование.** xᵢⱼ = (minₖ aᵏᵢⱼ, averageₖ bᵏᵢⱼ, maxₖ cᵏᵢⱼ). Для весов применяется та же схема. Формулы «Групповые оценки» требуют COUNT = 4.
3. **Нормализация.** Для MAX берётся c*ⱼ = maxᵢ cᵢⱼ и rᵢⱼ = (aᵢⱼ/c*ⱼ, bᵢⱼ/c*ⱼ, cᵢⱼ/c*ⱼ). Для MIN берётся a⁻ⱼ = minᵢ aᵢⱼ и rᵢⱼ = (a⁻ⱼ/cᵢⱼ, a⁻ⱼ/bᵢⱼ, a⁻ⱼ/aᵢⱼ). Нормирующие значения: C1 — 3, C2–C4 — 10.
4. **Взвешивание.** vᵢⱼ = (rᵃᵢⱼ · wᵃⱼ, rᵇᵢⱼ · wᵇⱼ, rᶜᵢⱼ · wᶜⱼ). Например, A1/C1: (0,3; 0,5; 1) × (0,7; 0,925; 1) = (0,21; 0,4625; 1).
5. **Идеал и антиидеал.** Для каждого критерия таблица выбирает покомпонентный максимум и минимум среди взвешенных альтернатив. Идеал здесь не задаётся фиксированной тройкой (1; 1; 1).
6. **Расстояния.** Для троек x и y: d(x,y) = sqrt(((xₐ−yₐ)² + (xᵦ−yᵦ)² + (x𝒸−y𝒸)²)/3). Итоги D⁺ᵢ = Σⱼ d(vᵢⱼ,v⁺ⱼ), D⁻ᵢ = Σⱼ d(vᵢⱼ,v⁻ⱼ).
7. **Коэффициент.** CCᵢ = D⁻ᵢ / (D⁺ᵢ + D⁻ᵢ). Чем выше CC, тем предпочтительнее концепция.
8. **Ранг.** RANK по CC по убыванию. Одинаковые CC получают одинаковое место; после двух вторых мест следует четвёртое.
