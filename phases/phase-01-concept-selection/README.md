# Фаза 1. Выбор концепции проекта

Статус: **расчёты TOPSIS, производного МАИ и сравнение выполнены**. Для подтверждения учебного результата остаётся согласовать E3 и правило преобразования баллов в парные сравнения.

Цель — выбрать концепцию для последующих фаз. [Исходная таблица](https://docs.google.com/spreadsheets/d/1eqROJSJggUz9f7V3TO8Hx18-0x1MoO2HRUv8ptMTKsc/edit) проверена 02.11.2026; [экспорт](artifacts/phase-01-topsis.xlsx) сохраняет 10 исходных листов и содержит 3 новых листа МАИ.

## Концепции и критерии

| Код | Концепция | Краткое описание |
|---|---|---|
| A1 | Запись на приём к врачу | Система для организации записи на врачебный приём. |
| A2 | Учёт вещей на хранении | Система учёта вещей, переданных на хранение. |
| A3 | Учёт обслуживания автомобиля | Система учёта обслуживания автомобиля. |
| A4 | Аренда инструментов между пользователями | Система организации аренды инструментов между пользователями. |

| Код | Критерий | Тип | Смысл |
|---|---|---|---|
| C1 | Сложность разработки проекта | MIN, затратный | Чем выше сложность, тем больше усилий требует разработка; предпочтительнее меньшее значение. |
| C2 | Практическая полезность | MAX, выгода | Предполагаемая ценность решения для пользователя. |
| C3 | Потенциал развития проекта | MAX, выгода | Возможность дальнейшего развития концепции. |
| C4 | Независимость от внешних систем | MAX, выгода | Возможность работы с меньшей зависимостью от сторонних систем. |

## Метод

Четыре анкеты преобразованы в нечёткие тройки. Групповые значения получают как минимум нижних границ, среднее центральных и максимум верхних. После нормализации MIN/MAX и взвешивания рассчитывают расстояния до покомпонентного идеала и антиидеала и CC. [Полная методика](topsis.md).

Анкета E3 заполнена медианами трёх остальных анкет; её происхождение раскрыто в [описании оценок](expert-ratings.md). Фактические трудозатраты участников не подтверждены.

## Результат и вывод

| Место | Код | Концепция | CC |
|---:|---|---|---:|
| 1 | A1 | Запись на приём к врачу | 1,0000 |
| 2 | A3 | Учёт обслуживания автомобиля | 0,4841 |
| 2 | A4 | Аренда инструментов между пользователями | 0,4841 |
| 4 | A2 | Учёт вещей на хранении | 0,3504 |

Для дальнейших фаз выбрана A1 «Запись на приём к врачу». Она совпала с идеалом текущей матрицы. A3 и A4 не различаются после группового агрегирования. [Анализ и сравнение](analysis.md); [расчёт МАИ](ahp.md). МАИ: A1 — 0,399169 (1), A2 — 0,239806 (2), A3 = A4 — 0,180512 (3). Оба метода выбрали A1.
