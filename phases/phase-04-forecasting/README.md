# Фаза 4. Прогнозирование

Статус: **не начата; заготовка**.

Объект прогноза — учебная работа команды по подготовке фазы 5.

1. Декомпозировать подготовку фазы 5 и собрать оптимистичные, наиболее вероятные и пессимистичные оценки времени.
2. Получить фактическую недельную историю закрытых задач и человеко-часов предыдущих фаз.
3. Построить модель Монте-Карло по эмпирическому распределению количества закрытых задач за неделю.
4. Построить модель по фактической недельной доступности в человеко-часах, выбирая трудоёмкость задач из треугольных распределений.
5. Получить 80-й процентиль срока обеих моделей, сравнить прогнозы и объяснить различия.

Ожидаемые артефакты: недельная история, трёхточечные оценки, код с фиксированным seed и параметрами запусков, распределения и два прогноза. TODO: собрать реальную историю; плановые часы не заменяют фактическую доступность.
